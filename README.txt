CART2MART PREMIUM — SHOPIFY THEME
===================================

This is an installable Shopify Online Store 2.0 theme ZIP.

INSTALL
1. Sign in to Shopify Admin.
2. Go to Online Store > Themes.
3. Click Add theme > Upload zip file.
4. Upload cart2mart-shopify-theme.zip.
5. Preview first, then Publish when ready.

AFTER INSTALLING
- Open Customize to set the hero image, hero text, categories, and featured collection.
- Add your own product photos and collections in Shopify Admin > Products / Collections.
- Create the collections linked in the category section or edit each category link in Customize.
- Set your store's shipping, payment provider, taxes, policies, and contact details in Shopify Admin.
- Update the announcement text and footer links in the theme code if needed.
- Theme currency formatting follows your Shopify store settings.

IMPORTANT
- Shopify does not import products, payment settings, shipping rules, or store policies with a theme ZIP.
- Hero banner image is intentionally a customizable image setting; upload the approved image in Customize.
- This theme is a custom starter theme, not a copy of a third-party commercial theme.
- Always preview and test product page, cart, checkout handoff, mobile layout, and policy links before publishing.

DARK / LIGHT MODE
- Header toggle switches between dark and light appearance. Preference is saved in the browser.
- The theme starts in dark mode by default.
